# 基于软件无线电设备的 AM 与 FM 信号接收与解调 — 技术方案

## 1. 项目概述

本课程设计基于 RTL-SDR Blog V4 软件无线电接收机，完成对 AM/FM 广播信号的接收、基带数据采集、频谱分析以及离线和实时解调，最终输出期刊论文格式的实验报告、PPT 及讲解视频。

---

## 2. 总体技术路线

```
┌──────────┐    ┌──────────────┐    ┌─────────────┐    ┌────────────────┐
│  AM/FM   │    │  RTL-SDR     │    │   PC/SDR#   │    │    MATLAB      │
│  广播电台 │───→│  Blog V4     │───→│  IQ数据采集   │───→│  解调 + GUI     │
│  信号源   │    │  接收机       │    │  基带存储     │    │  频谱分析       │
└──────────┘    └──────────────┘    └─────────────┘    └────────────────┘
```

**工作流程：**
1. RTL-SDR Blog V4 通过天线接收空间中的 AM/FM 广播射频信号
2. 射频前端（R828D 调谐器）完成下变频和滤波，输出中频信号
3. RTL2832U 芯片对中频信号进行 AD 采样和数字下变频（DDC），输出 IQ 基带数据
4. 通过 USB 将 IQ 数据流传输至 PC
5. 使用 SDR# 软件配置参数并可视化频谱/瀑布图，导出 IQ 基带数据文件
6. MATLAB 读取基带数据进行离线频谱分析与解调；同时通过 RTL-SDR 驱动实现实时解调

### 3.2 关键芯片与模块分析

#### 3.2.1 射频前端 — R828D 调谐器

| 参数 | 指标 |
|------|------|
| 频率范围 | 24 MHz ~ 1.7 GHz |
| 噪声系数 (NF) | 约 3.5 ~ 5 dB |
| 增益控制 | LNA + Mixer 两级增益可调 (0 ~ 49.6 dB) |
| 中频输出 | 低 IF 架构，典型 IF 频率可配置 |
| 镜像抑制 | 取决于 IF 滤波器，约 30 ~ 40 dB |
| 输入阻抗 | 75 Ω（SMA 接口） |

**工作原理：**
- LNA（低噪声放大器）：对天线接收的微弱射频信号进行第一级放大，在保证低噪声的前提下提高信号强度
- 混频器（Mixer）：将 RF 信号与本地振荡器（LO）信号相乘，实现频谱搬移，输出中频（IF）信号
- PLL 频率合成器：提供可编程的 LO 频率，步进精度决定调谐分辨率

#### 3.2.2 数字基带处理器 — RTL2832U

| 参数 | 指标 |
|------|------|
| ADC 分辨率 | 8 bit |
| 最大采样率 | 3.2 MSPS |
| ADC 类型 | Pipeline ADC |
| SNR (理论) | 约 49.9 dB（8 bit 理想值） |

**内部关键模块：**

**（1）模数转换器（ADC）**
- 8-bit 流水线型 ADC，最大采样率 3.2 MSPS
- 对 R828D 输出的 IF 模拟信号进行数字化
- 量化噪声：8 bit 对应约 48 dB 动态范围

**（2）数字下变频（DDC）**
```
IF输入 ──→ 混频器(Mixer) ──→ 低通滤波(LPF) ──→ 抽取(Decimation) ──→ IQ基带输出
                ↑
           NCO (数控振荡器)
```

- NCO（数控振荡器）：产生正交的正弦/余弦信号，将 IF 搬移至基带
- 低通滤波器：滤除混频产生的二倍频分量，保留基带信号
- 抽取器：降低采样率到用户设定的输出速率（250 kHz ~ 3.2 MHz）
- 输出：IQ 正交基带信号（I 路同相分量，Q 路正交分量）

**（3）USB 2.0 控制器**
- 将 IQ 采样数据打包通过 USB 2.0 传输至 PC
- 最大带宽：约 480 Mbps（理论），实际稳定传输约 2.56 MSPS（I+Q 各 8 bit）

### 3.3 信号链路参数估算

以 FM 广播（中心频率 100 MHz，带宽 200 kHz）为例：

```
RF: 100 MHz  ──→ IF: 3.57 MHz (典型值) ──→ ADC采样: 3.2 MSPS ──→ DDC输出: 250 kSPS IQ
                                                                     (I路+Q路各250kSPS)
```

## 4. SDR# 软件使用方案

### 4.1 参数配置

| 参数 | AM 广播 | FM 广播 |
|------|---------|---------|
| 中心频率 | 530 ~ 1710 kHz | 88 ~ 108 MHz |
| 采样率 | 1.024 MSPS | 2.4 MSPS |
| 增益 | 手动调整至 SNR 最佳 | 手动调整至 SNR 最佳 |
| 解调模式 | AM | WFM（宽带 FM） |
| 解调带宽 | 10 kHz（AM 带宽 9~10 kHz） | 200 kHz（FM 广播带宽） |
| 输出采样率 | 48 kHz（音频） | 48 kHz（音频） |

### 4.2 操作步骤

1. 安装 RTL-SDR 驱动（Zadig 工具安装 WinUSB 驱动）
2. 启动 SDR#，选择 RTL-SDR (USB) 作为信号源
3. 根据目标电台设置中心频率
4. 调节 RF 增益（逐步增大，直到噪声地板开始抬升，然后回退 3~6 dB）
5. 观察频谱图和瀑布图，确认信号出现
6. 切换至对应解调模式（AM/WFM），调节音量至清晰
7. 截图保存频谱图与瀑布图
8. 使用 SDR# 的 IQ 录制功能保存基带数据（File → Start IQ Recording），AM/FM 各录制 20 秒

### 4.3 IQ 基带数据格式

- 格式：Raw IQ，8-bit unsigned integer，I 和 Q 交替存储（I₀, Q₀, I₁, Q₁, ...）
- 采样率：用户在 SDR# 中设置的采样率（应 > 信号带宽的 2 倍，满足奈奎斯特准则）
- 文件名示例：`FM_100MHz_2.4MSPS.iq`

## 5. MATLAB 离线处理方案（任务 4）

### 5.1 基带数据读取

```matlab
function [iq_signal, fs] = read_iq_file(filename, sample_rate)
    % 读取 SDR# 录制的 IQ 原始数据
    % 格式: 8-bit unsigned int, I/Q 交替
    fid = fopen(filename, 'rb');
    raw_data = fread(fid, inf, 'uint8');
    fclose(fid);
    
    % 分离 I/Q 并转换为有符号数 (0~255 → -128~127)
    I = raw_data(1:2:end) - 127.5;
    Q = raw_data(2:2:end) - 127.5;
    iq_signal = complex(I, Q);
    fs = sample_rate;
end
```

### 5.2 频谱分析

```matlab
function plot_spectrum(iq_signal, fs, title_str)
    N = length(iq_signal);
    % 计算功率谱密度 (Welch法)
    [pxx, f] = pwelch(iq_signal, hann(4096), 2048, 8192, fs, 'centered');
    plot(f / 1e3, 10 * log10(pxx));
    xlabel('频率 (kHz)');
    ylabel('功率谱密度 (dB/Hz)');
    title(title_str);
    grid on;
end
```

### 5.3 AM 解调算法

AM 信号数学表达式：$s(t) = [A_0 + m(t)] \cos(2\pi f_c t + \phi)$

**方案：包络检波**

```matlab
function audio = am_demodulate(iq_signal, fs, audio_fs)
    % 1. 取包络（幅度）
    envelope = abs(iq_signal);
    
    % 2. 去直流（去掉 A₀ 分量）
    envelope = envelope - mean(envelope);
    
    % 3. 低通滤波（截止频率 = 音频带宽 ≈ 5kHz）
    lp_filter = designfilt('lowpassfir', ...
        'PassbandFrequency', 4000, ...
        'StopbandFrequency', 5000, ...
        'PassbandRipple', 0.1, ...
        'StopbandAttenuation', 60, ...
        'SampleRate', fs);
    audio_raw = filter(lp_filter, envelope);
    
    % 4. 降采样到音频采样率
    audio = resample(audio_raw, audio_fs, fs);
    
    % 5. 归一化
    audio = audio / max(abs(audio));
end
```

**原理说明：**
- 对 IQ 复信号取模 $|I + jQ| = \sqrt{I^2 + Q^2}$ 即得到信号包络
- 包络等于 $A_0 + m(t)$，去掉直流分量 $A_0$ 后即为调制信号 $m(t)$
- 低通滤波去除带外噪声，提高音质

### 5.4 FM 解调算法

FM 信号数学表达式：$s(t) = A \cos\left(2\pi f_c t + 2\pi k_f \int_0^t m(\tau) d\tau\right)$

**方案：正交鉴频**

```matlab
function audio = fm_demodulate(iq_signal, fs, audio_fs)
    % 1. 计算瞬时相位
    phase = unwrap(angle(iq_signal));
    
    % 2. 差分得到瞬时频率（离散域）
    freq_inst = diff(phase) * fs / (2 * pi);
    freq_inst = [freq_inst(1); freq_inst];  % 保持长度一致
    
    % 3. 去均值（消除频偏）
    freq_inst = freq_inst - mean(freq_inst);
    
    % 4. 低通滤波（音频带宽 ~15 kHz for FM广播）
    lp_filter = designfilt('lowpassfir', ...
        'PassbandFrequency', 15000, ...
        'StopbandFrequency', 18000, ...
        'PassbandRipple', 0.1, ...
        'StopbandAttenuation', 60, ...
        'SampleRate', fs);
    audio_raw = filter(lp_filter, freq_inst);
    
    % 5. 降采样
    audio = resample(audio_raw, audio_fs, fs);
    
    % 6. 去加重（FM 广播标准 50 μs 去加重网络）
    tau = 50e-6;
    alpha = exp(-1 / (audio_fs * tau));
    audio = filter(1 - alpha, [1, -alpha], audio);
    
    % 7. 归一化
    audio = audio / max(abs(audio));
end
```

**原理说明：**
- FM 信号的信息包含在瞬时频率变化中，瞬时频率 $f(t) = \frac{1}{2\pi} \frac{d\phi(t)}{dt}$
- 通过计算相邻采样点相位差近似微分，得到瞬时频率
- 瞬时频率的变化量正比于调制信号 $m(t)$
- 去加重网络补偿发射端的预加重，使音频频谱恢复平坦

## 6. MATLAB 实时解调方案（任务 5）

### 6.1 实时数据获取

使用 MATLAB 的 Communications Toolbox 或第三方 RTL-SDR 驱动包：

```matlab
% 创建 RTL-SDR 接收器对象
rx = comm.SDRRTLReceiver('0', ...
    'CenterFrequency', 100e6, ...
    'SampleRate', 2.4e6, ...
    'OutputDataType', 'double', ...
    'SamplesPerFrame', 4096, ...
    'EnableTunerAGC', false, ...
    'TunerGain', 20);
```

**备选方案：** 若无 Communications Toolbox，使用 [rtl_tcp](https://github.com/osmocom/rtl-sdr) 命令行工具将 RTL-SDR 数据通过 TCP 流式传输，MATLAB 通过 TCP socket 接收：

```
# 命令行启动 rtl_tcp
rtl_tcp -a 127.0.0.1 -p 1234 -f 100e6 -s 2.4e6
```

MATLAB 端通过 `tcpclient` 读取实时 IQ 数据流。

    'BufferSize', 4096);

    % 解调

## 10. 关键风险与应对

| 风险 | 应对措施 |
|------|---------|
| RTL-SDR 驱动安装失败 | 使用 Zadig 正确安装 WinUSB，避免选择错误设备 |
| 信号接收质量差 | 调整天线位置/增益，考虑使用室外天线 |
| MATLAB 实时处理延迟 | 降低帧大小、优化解调循环、使用 filter 替代 `filter` 函数 |
| Communications Toolbox 不可用 | 使用 rtl_tcp + TCP 方案替代 |
| 基带数据文件过大 | AM: 1.024MSPS × 20s × 2byte = 40MB；FM: 2.4MSPS × 20s × 2byte = 96MB；存储可控 |
